Cartouche Installer 0.2.5 pairs again by itself with an iPhone that was erased or set up again.

- Paired again: an iPhone erased or set up again now pairs again by itself. The installer asks your iPhone whether it still knows the pairing it kept for it, and makes a new one when it does not, so Cartouche no longer says "This iPhone did not answer through LocalDevVPN" after a reset. Not tried on a real iPhone yet.

## Downloads

- **Mac**, Apple silicon and Intel, macOS 11 or later. `Cartouche-Installer-0.2.5-Mac.dmg`. The first time you open the app, use **System Settings › Privacy & Security › Open Anyway** if macOS asks.
- **Windows** 10 or 11. `Cartouche-Installer-0.2.5-Windows.exe`. If SmartScreen stops it, choose **More info › Run anyway**. Windows needs **Apple Devices** from the Microsoft Store, or iTunes, to reach the iPhone.
