# 169. A game nxnative stops for lack of room on the disk says so, and Cartouche warns before a start that may end that way

2026-11-26

On the iPhone, nxnative keeps a game's memory in files when the game's memory pool and the host's margin do not fit under the memory limit (`DM_GUEST_FILE`, `hle_svc.c`). Switch 2 games, with a 9 GB pool, do. The files take up to the pool on the disk as the game touches its memory. nxnative stops the game, with exit code 87, once the room left there, what is free less what the dirty pages may still take, falls under 2 GB (`DM_GUEST_FILE_MIN_FREE`), or under half of that on its own. It does so even when iOS counts much more as available, because iOS frees what it could purge, such as iCloud Drive downloads and caches, only once it runs short itself, too late for the game. Cartouche said only that the game had closed on its own, and the player had no way to know why.

Cartouche now reads nxnative's words in the game's log (`CartoucheGameRoom`):

- **After the stop.** When nxnative stopped a game behind the console for lack of room, the notice says so. It gives what was free and, when iOS counted much more as available, explains that iOS frees the rest too late. The game is not moved to Cartouche's place or started again, since memory is not what it lacked.
- **Before a start.** If the game's last start kept its memory in files, and what is free now, without what iOS could purge, is under its pool plus nxnative's minimum, Cartouche warns that the game may close for lack of space and offers Play anyway. It warns once per game while Cartouche stays open. The next start goes ahead, so a player with a controller presses A, then Play again.
- **Measures.** The session's `end.cause` is `diskFull`, with the kind `unknown`, from the log reader's sixth reading. It is never `memory-likely`, even close to the memory limit.
- **On the Mac.** nxnative keeps a game's memory in files only when the player turns `DM_GUEST_FILE` on, since the Mac sets no memory limit. For exit 87, the console says the Mac's disk ran out of room for the game's memory, with what was left, instead of saying it stopped unexpectedly. It gives no warning before a start.

Cartouche does not ask iOS to purge, and does not change nxnative's threshold. Both belong to nxnative, and what to send them is up to the player.

**Why.** A problem report of 26 November 2026: a game stopped within seconds, start after start, on an iPhone with a few GB free and tens of GB that iOS counted as available, and Cartouche said only that it had closed on its own. The figures stay in the private report.
