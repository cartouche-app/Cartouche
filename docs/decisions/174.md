# 174. A game's pipeline archive is made for the GPUs of the paired iPhones too

2026-11-26

nxnative makes, for a game whose profile turns `pso_mtl4` on, the Metal 4 path, which alone reads it on iOS, the bases of the game's pipelines on the Mac with Xcode's `metal-tt`, one archive for each GPU architecture, and puts them in the IPA (`pso/applegpu_<GPU>.mtl4a`). A device whose GPU has one builds no base at the game's first start; one whose GPU has none builds them all then, which takes minutes once ("Pipeline prebuild"). By default nxnative makes one for the profile's `pso_gpu`, else for `g18p`, the A19 and A19 Pro of the iPhone 17 family; its build script takes the architectures as `--gpu`, which replaces that default. The Legend of Zelda: Breath of the Wild is the only game with `pso_mtl4` on at nxnative's `2f959ede` (26 November 2026), with no `pso_gpu`.

Cartouche now tells its paired Mac, beside the iPhone's model and whether its GPU reads BC, the architecture of its GPU as Metal names it (`MTLDevice.architecture`, "applegpu_g18p") and the major version of its iOS ([`CartoucheBridge.swift`](../../launcher/Sources/CartoucheBridge.swift), `CartoucheBridgeDevice`), each time it connects; the Mac keeps them with the paired iPhone ([`BridgeDevices.swift`](../../builder/mac/Sources/BuilderKit/BridgeDevices.swift)). A name that is not an architecture, and a Mac's console, say none.

For a game whose profile asks for an archive, Cartouche Builder passes `--gpu` with the profile's default first, then the GPU of each paired iPhone ([`pipelines.py`](../../builder/cartouche_builder/pipelines.py)):

- only an iPhone on the iOS the archive is made for, the major version of the iOS SDK (nxnative's `DM_PSO_IOS_MIN` by default): an iPhone opens only an archive made for its own;
- four GPUs at most, as a profile's `pso_gpu` names: each adds about 650 MB to the app on every iPhone it goes to, 220 MB to the IPA, and minutes to the build;
- without `--gpu` when no paired iPhone adds one, nxnative's default then standing, and never for a game whose profile asks for none, nor for a Mac's app, nor with a checkout whose script does not take it.

`metal-tt` fails for a GPU it does not know, and nxnative then packs the app with no archive at all, the default's too ("pipeline archive: pso_offline.py failed"). The Builder then keeps that GPU among those this Xcode and iOS SDK refuse (`pipelines.json`), builds the game again at once without it, and leaves it out until the tools change. The game's log says, as a line of the Builder's, which GPUs its archive is for, which the paired iPhones added, and why one was left out, never an iPhone's name. The batch's status gives each game's GPUs, and the Builder's state keeps those of each IPA it built.

The game measurements say what the game found as it started, from nxnative's log: its archive opened (`opened`), none for this GPU (`otherGPU`), none for this iOS (`otherSystem`) or a file that is no archive (`unreadable`), as `pipelineArchive`, and, once the first start built bases, how long it took and how many it built and found archived, as `prebuild`, on the iPhone and the Mac alike ([`CartoucheGameLog.swift`](../../launcher/Sources/CartoucheGameLog.swift), reader 7). `builder.built` says how many GPUs the archive was made for and how many the paired iPhones added (`gpus`, `gpusAdded`), never which ([telemetry/README.md](../../telemetry/README.md#reports)).

Not done yet: a game built before an iPhone was paired gets its GPU at its next build, not at once; every iPhone installs every archive of the IPA, its own GPU's alone being read; Cartouche Cloud builds with nxnative's default. None of it has been tried on a real iPhone or Mac yet: the Builder's tests run nxnative's build with a stand-in that takes `--gpu` and a `metal-tt` that refuses a GPU.

**Why.** nxnative does it and Cartouche did not take it up (Ad, 26 November 2026, "Toutes les six"). Breath of the Wild's first start on an iPhone whose GPU is not the A19's built its pipelines for minutes, while the Mac that built the game knew that iPhone. Counting the archives found and the bases built tells, before and after, whether it helps. Keeping the default first and dropping a GPU `metal-tt` refuses keeps every iPhone 17's archive whatever another paired iPhone is.
