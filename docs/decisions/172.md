# 172. What nxnative's main tells the apps that run its games is read each week, into a private issue

2026-11-26

nxnative has no releases and no tags: Cartouche follows its `main`. nxnative's `docs/frontends.md` (Following main) says what an app that runs its games reads between the commit it last read and the one it moves to: the `Front-ends:` lines of the commits' messages (`break`, `interface`, `new`), the changes to `docs/frontends.md`, `docs/launcher.schema.json` and `dm/games/settings.tsv`, the NSP script's options, the environment switches of `docs/env_switches.tsv` with their class, and the shader chain.

A workflow of the private repository `cartouche-app/cartouche-reports`, **nxnative watch** (`nxnative_watch/watch.py` there), reads all of it on Thursdays from the last commit read, and the games whose profile was added or removed. With it, against Cartouche's `main`, it lists:

- each text of nxnative's `dm/games/settings.tsv` that `CartoucheText.gameSettingText` ([`launcher/Sources/CartoucheText.swift`](../../launcher/Sources/CartoucheText.swift)) has no case for, which a player sees in English whatever their language, on the iPhone and the Mac;
- each game language of nxnative's `dm/tools/nacp.py` that `CartoucheGameLanguage.codes(for:)` ([`launcher/Sources/CartoucheGameLanguage.swift`](../../launcher/Sources/CartoucheGameLanguage.swift)) never gives, so that an iPhone in that language gets the build's;
- how many commits [`catalog/nxnative.commit`](../../catalog/nxnative.commit) is behind nxnative's `main`.

When something changed upstream, or a text or a language is newly missing in Cartouche, it opens an issue labelled `nxnative-watch` there, or adds the week's report to the one still open, each line a task to tick. A marker at the end of each report holds the last commit read, which the next run starts from; the first starts from `2f959ede`, read by hand on 26 November 2026. Nothing is run of nxnative's, and nothing goes to nxnative: its words are escaped so that the issue neither notifies nor references anyone on GitHub. Cartouche's own files are only read.

**Why.** Between 4 and 27 November, nxnative's commits carried 55 `Front-ends:` lines, read by hand once, on 26 November: that reading found settings Cartouche showed in English (Rotation, Texture filtering, Microphone), Polish and Thai, which no iPhone picked, and save files Cartouche's copies did not carry. A reading each week finds them as they come, without a thread having to think of it. The issue is in the private repository, not in Cartouche's, because nxnative's own words, its page and some of its commits, name other apps that run its games, which Cartouche's repository never names.
