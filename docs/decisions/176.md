# 176. The question before an install reads the game's build: one that converts the BC textures installs without it

2026-11-27

On an iPhone whose GPU reads no BC-compressed texture, the A16's and older, Cartouche asks before it installs a game (*This iPhone cannot run nxnative's games*, *Install anyway* or *Cancel*, [decision 67](../decisions.md)). It now asks only when the game's build does not convert those textures for every API nxnative's list draws the game with, as its sheet says it ([`CartoucheBCConversion.covers`](../../launcher/Sources/CartoucheBCConversion.swift)); a build that converts them, as nxnative-nobc's do, installs at once ([`CartoucheInstallQuestions.swift`](../../launcher/Sources/CartoucheInstallQuestions.swift), [`CartoucheGameActions.swift`](../../launcher/Sources/CartoucheGameActions.swift)). What Cartouche knows of the build before the install:

- **An IPA on the iPhone**, from Files or another app: its executable read in place, its entry alone unpacked to a file then removed, as a game's in a games folder is (`CartoucheBCConversion.conversion(ofIPA:)`). It is the install's first check, *Checking…*, and only on such a GPU, unless the player answered *Install anyway*.
- **A game in a games folder or on the paired Mac**: what Cartouche read of its build after the folder's list ([decision 145](145.md)). A copy not read yet asks, as before.
- **A game Cartouche Cloud built**: the nxnative the platform says it built it from, `engine` in the account's games (`GET /api/app/games`): from nxnative-nobc, for an iPhone 11 to 15, its NVN and Vulkan textures are converted (`CartoucheBCConversion.conversion(ofCloudEngine:)`). Its sheet, before the install, says so too: *Textures converted for this GPU by this game's build*.

A build Cartouche could not read asks, as nxnative's own builds do; nothing here lifts the question for a build it did not read. The System page's note stays as it is. This amends [decision 137](137.md) and [decision 145](145.md), under which the question came before Cartouche had a build to read and stayed as it was.

**Why.** On 26 November 2026, a player with an iPhone 13 sent Sparking Zero to Cartouche Cloud for an iPhone 11 to 15, downloaded the IPA it built from nxnative-nobc, and opened it in Cartouche, which still said the iPhone could not run it. The question looked at the GPU alone. Once installed, the game's sheet said its textures were converted, and the session's report said `bcTextures: converted`. Since [decision 150](150.md) Cartouche on the Mac builds from nxnative-nobc for such an iPhone, and Cartouche Cloud does since 26 November: the question told every player who followed its own advice that their game could not run. The executable of a file on the iPhone is read in a few seconds, and only on such a GPU; a game of Cartouche Cloud is read nowhere before its install, and the platform, which chose the fork for the iPhone the player named, says which one it used.
