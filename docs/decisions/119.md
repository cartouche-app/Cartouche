# 119. Every Mac job of the CI runs on GitHub's Macs, and Ad's Mac leaves the CI

2026-11-15

The app's build (**Build Cartouche.ipa**, [App](../../.github/workflows/app.yml)) and the launcher's UI tests on an iPhone ([Launcher screens](../../.github/workflows/screens.yml)) run on GitHub's Macs (`xcode-27`), as every other Mac job of the CI. The job that sent them to Ad's Mac when it could take them (**Ad's Mac or GitHub**), the one that watched them there (**Watch Ad's Mac**), Mac rescue, and what the Mac ran (the runners' hooks, their supervisor, `cartouche-ci` and its installer, in `.github/mac`) are gone, with the secret they read, `MAC_RUNNER_TOKEN`. Reverses [decision 73](../decisions.md).

**Why.** Decision 73 sent the two jobs to Ad's Mac because GitHub ran five macOS jobs at a time for the whole account, and a job waited for one. Since the repository moved to an organization on GitHub Enterprise Cloud ([decision 111](111.md)), GitHub runs fifty, and no job waits for a Mac. No job has gone to Ad's Mac since the move either: the route sent it only the runs started by the repository's owner, now the organization ("GITHUB_ACTOR is 'clabeuhtegrite', not the repository's owner", run 43735681923). What was left was a job more before the build and the UI tests of every pull request, and code kept for nothing. Ad chose for the Mac to leave the CI once the repository had moved (2026-11-14).
