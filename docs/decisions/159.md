# 159. Once the first game is installed, the home says the automation of every night is left, and Cartouche asks to warn before it expires

2026-11-25

Signed with an Apple ID and set up, once the player's first game is installed, the banner at the top of the home says **Renew every night** while the automation of Shortcuts is still to make: "So that Cartouche renews itself, even if you leave it closed for a week." A tap opens the setup at its end, on that step, whose button opens the automation's page ([decision 149](149.md)). Its ×, as the guide's card has, takes it off the home for good: the setup's step and the System page still offer the automation. The banner goes once the player says they made the automation, or once a run of it is noted; the setup's three first steps, and Increased Memory Limit for the IPA of the player's own SideStore, keep the banner first, as before ([`CartoucheSetupView.swift`](../../launcher/Sources/CartoucheSetupView.swift), `CartoucheSetup.nightlyLeft`).

At the same moment, as the first game's install ends, Cartouche asks iOS for the permission to send its warnings, 24 hours and 6 hours before its signature expires, if nothing asked for it yet ([`CartoucheRenewal.swift`](../../launcher/Sources/CartoucheRenewal.swift), `allowAlertsAfterFirstGame`). Asked or answered before, iOS shows nothing, and the System page's button stays the way to them. With the player's own certificate, which Cartouche never renews, there is neither the banner nor the question.

On the Mac, as the rule that the Mac mirrors the iPhone asks ([decision 95](095.md)), nothing changes: a Mac app does not expire, and the console has no setup banner.

This amends [decision 149](149.md), whose banner kept to the setup's first three steps.

Not tried on an iPhone yet: iOS's question as the first game's install ends.

**Why.** Walking a new player's way from cartouche.cloud to a first game, for the 1.0's gate (someone close installs and plays without help), on 25 November 2026: once the first game is installed, the guide leaves the home, and nothing there says that a Cartouche no one opens for a week expires, which then takes a computer to install again. The automation that prevents it was the setup's last step alone, which a player who plays never opens, and the warnings needed a button of the System page. Put to Ad on 25 November 2026, as the walk's next step.
