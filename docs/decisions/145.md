# 145. A build that converts a Vulkan game's BC textures lifts its warning too, and the sheet no longer says *to ASTC*

2026-11-24

A fork of nxnative that converts BC textures for a GPU that reads none, the `no-bc` branch of [mianmuhammadse/nxnative](https://github.com/mianmuhammadse/nxnative/tree/no-bc), does so in its Vulkan layer too since 22 November 2026 (its commit 53f5d9a, `dm/gfx/vk/hle_vk.m`): BC1 to BC3 images stored as ASTC 4x4, the others decompressed, as its NVN layer does. Such a build says so in its executable's C strings, in the line its Vulkan layer logs at the first BC image it stores otherwise (`[vk] no BC:`), where a build whose Vulkan layer does not convert has no such words. Cartouche now reads, of each installed game's executable, which APIs its build converts, NVN's (`DM_NO_BC_ASTC`, as before) and Vulkan's ([`CartoucheBCConversion.swift`](../../launcher/Sources/CartoucheBCConversion.swift)), none when it carries either of nxnative's refusals. A game whose build converts the textures of every API nxnative's list draws it with, NVN or NVN2, and Vulkan, is no longer *Not supported* for its GPU; one drawn with OpenGL, or with Vulkan by a build that converts NVN's alone, keeps its warning. Of a game the list does not know, the build's word stands, as before.

The sheet's BC line of such a game says *Textures converted for this GPU by this game's build*, no longer *Textures converted to ASTC by this game's build*: BC1 to BC3 become ASTC, the others are decompressed. The telemetry's `bcTextures` still says whether a build converts any of them. Nothing changes on a Mac, whose GPU reads BC textures. This amends [decision 137](137.md), under which the conversion covered NVN's games alone.

**Why.** The fork's author, who asked for the warning to go on Cartouche's Discord, wrote on 19 November that *converted to ASTC* says more than his build does: BC4, BC5, BC6H, BC7 and 3D textures are decompressed. His Vulkan layer then converted too, after Until Then, a Vulkan game, stopped at its first BC image on his iPhone 15; the telemetry of 21 to 23 November shows it: a session of 0 minutes with the build before that commit (`ada1018b`), then 35, 137 and 18 minutes in all with the three builds since (`bcTextures: converted`). Reading the Vulkan layer's own words, rather than the setting's name alone, lifts the warning of a Vulkan game such as Hades or Super Mario Galaxy only for a build that converts its textures, and keeps it for a build that converts NVN's alone.
