# 147. A player who has SideStore installs Cartouche with it, from a source of its own, without a computer

2026-11-24

A player who already has SideStore on the iPhone adds Cartouche's source for SideStore to it, [`app/sidestore-player-source.json`](../../app/sidestore-player-source.json), and installs Cartouche from it, with no computer. That source lists a third IPA of each release, `Cartouche-<version>-SideStore.ipa`, which the Release workflow makes from the release's own IPA ([`sidestore_ipa.py`](../../app/scripts/sidestore_ipa.py)) and adds to both the release and that source ([`add_release.py`](../../app/scripts/add_release.py)). It is the release's IPA, file for file, with three changes:

- an app group of its own, `group.com.SideStore.SideStore.cartouche`, in the entitlements of the app, of LiveProcess and of the widget, which ldid signs again, in place of LiveContainer+SideStore's `group.com.SideStore.SideStore`, and without AltStore's;
- in its Info.plist, `CartoucheSideStoreInstall`, which tells Cartouche how it was installed (`CartoucheSigningMode.sideStore`, `sidestore` in the measurements' `signing`), `CartoucheAppGroup`, that group, and `CartoucheSourceURL`, the source for SideStore, which LiveContainer and the built-in SideStore read in place of their own ([`livecontainer/0018`](../../app/patches/livecontainer/0018-take-the-built-in-sidestores-app-group-and-source-from-the-info-plist.patch));
- `ALTAppGroups` with that group alone.

The player's SideStore asks whether to keep the extensions: **Keep App Extensions (Use Main Profile)** uses a single App ID of the ten a free account has each week, as the Cartouche Installer signs them ([decision 105](../decisions.md)).

The setup then has four steps ([`CartoucheSideStoreInstall.swift`](../../launcher/Sources/CartoucheSideStoreInstall.swift), [`CartoucheSetupView.swift`](../../launcher/Sources/CartoucheSetupView.swift)):

1. **Pairing file**: **Ask SideStore** opens `sidestore://pairing?urlname=cartouche`, a link SideStore already answers, by opening `cartouche://pairingFile?data=<the file in base64>` ([`CartoucheSideStoreLink.swift`](../../launcher/Sources/CartoucheSideStoreLink.swift)). Cartouche takes that answer only in this IPA and for ten minutes after it asked; any other is left alone. Choosing the file stays.
2. **Apple ID**: the one the player's SideStore uses. The sign-in takes the certificate that SideStore signed Cartouche with, which it leaves in every app it signs (`ALTCertificate.p12`, [`sidestore/0012`](../../app/patches/sidestore/0012-find-the-certificate-a-computer-left-in-the-app.patch)): nothing is created or revoked ([`sidestore/0004`](../../app/patches/sidestore/0004-never-revoke-a-certificate.patch)). With another Apple ID, the sign-in says to use that one, or to install Cartouche again from the player's SideStore.
3. **Certificate**, as before.
4. **Increased Memory Limit**: SideStore leaves it out on a free team ([SideStore#1616](https://github.com/SideStore/SideStore/issues/1616)), and iOS then gives Cartouche and its games about 3 GB. Once the first three steps are done, **Reinstall Cartouche** has the built-in SideStore install the version that runs again, from the source for SideStore, signed by itself, which asks Apple for the capability ([`sidestore/0002`](../../app/patches/sidestore/0002-request-increased-memory-limit-for-free-teams.patch), [`sidestore/0025`](../../app/patches/sidestore/0025-let-cartouche-install-itself-again-through-the-built-in-sidestore.patch), [`CartoucheUpdates.reinstallForMemory`](../../launcher/Sources/CartoucheUpdates.swift)). As Cartouche opens again, it says whether iOS gives it now. Until then, the home's banner offers it.

After that, the built-in SideStore renews and updates Cartouche as it does any other install, from the source for SideStore, with the IPA of each version for the player's SideStore. This amends [decision 15](../decisions.md) for that IPA alone: every other IPA keeps LiveContainer+SideStore's app group.

Nothing of this has been tried on an iPhone yet: the player's SideStore's **Refresh All** on Cartouche, which installs profiles only, has to be checked for the capability it may drop.

**Why.** Players who already have SideStore ask how to install Cartouche without a computer (Reddit, 2026-11-18), and Ad chose this variant, from a source rather than an IPA (2026-11-24). The release's IPA cannot go there as it is: the player's SideStore registers the groups an app's entitlements name, so Cartouche's would be `group.com.SideStore.SideStore.<team>`, the very group that SideStore keeps its own database in (`Database/SideStore.sqlite`). Each SideStore would then find the other's database, newer or older, and offer to reset it, with the list of the player's apps. A group that begins with the built-in SideStore's keeps every test LiveContainer makes of its beginning, and is never the player's SideStore's. The pairing file and the certificate are already on the iPhone, in the player's SideStore, which hands both over through means it already has, so that neither a computer nor a new certificate is needed. The one reinstall is the only way to Increased Memory Limit, without which most games do not run, that leaves the player's SideStore as it is: no pull request, issue or comment of ours goes to SideStore, whose rules refuse those an AI writes.
