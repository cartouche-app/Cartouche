# 141. Several games folders at once, a game in more than one offered from a folder that answers

2026-11-24

The player may choose several games folders on the Storage page, on any of their servers (Add another games folder): Cartouche reads them all ([`CartoucheStorageSettings`](../../launcher/Sources/CartoucheStorage.swift) `otherGames`, [`CartoucheStoredGames`](../../launcher/Sources/CartoucheStoredGames.swift)). The first is the games folder as before: the one a game is copied to before it is uninstalled, and the one the paired Mac sends its builds to; stop using it, or remove its server, and the next takes its place ([`CartoucheGamesFolderList`](../../launcher/Sources/CartoucheGameCopies.swift)).

A game in several folders shows once in the library, under the same entry whichever copy is offered. The copy offered is, in this order ([`CartoucheGameCopies`](../../launcher/Sources/CartoucheGameCopies.swift)):

- one on a server that answers from here, before one on a server that does not, as a NAS away from home, even a newer build;
- between two that answer, or two that do not, the newer build (`CartoucheGameBuild.isNewerCopy`), else the one written there last, else the one of the folder listed first.

Its sheet says where the others are ("Also in NAS (offline)."). An install that finds the server of the copy offered offline goes on from the game's next copy, in the same order, and says so in its report.

The paired Mac is told the other folders with the games folder (`CartoucheChosenFolders.otherGames`, chosen with it): Cartouche Builder sends its builds to the first only, and Cartouche's console on the Mac offers the Mac apps another Mac sent to any of them, a game in several once, by the same order ([`ConnectionGames.macApps(in:known:)`](../../builder/mac/Sources/BuilderKit/ConnectionGames.swift)), its install going on from the next folder when that one does not answer. Its Storage page lists them under the iPhone's games folder.

**Why.** Ad, 24 November 2026: a game kept on several storages, some offline, should be offered from one that is reachable, which means managing several games folders at once. A NAS at home does not answer away from home, where a Google Drive or an S3 bucket does: with one games folder, the library said "offline" for a game the player has a copy of elsewhere. Reachability comes before the build because the player wants to play now; the first folder stays the one copies go to, so that adding a folder changes nothing of where Cartouche writes.
