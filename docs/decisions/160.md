# 160. The site offers the source for the player's own SideStore, names nxnative-nobc for the iPhones without BC, and shows every feature of Cartouche

2026-11-25

Amended by [decision 161](161.md): the site names these features and the documentation, at docs.cartouche.cloud, details them; nxnative-nobc is named in *What you need*.

The showcase site, [`site/`](../../site/README.md), offers Cartouche's source for the player's own SideStore ([decision 147](147.md), [decision 155](155.md)):

- The install's second step, `#sidestore`, says to a player who already has SideStore to add Cartouche's source, **https://source.cartouche.cloud**, which it shows in the four languages, and to install Cartouche from it choosing **Keep App Extensions (Use Main Profile)**, with no computer; that its setup asks SideStore for the pairing file and takes its certificate, then that Cartouche installs itself again, once, for Increased Memory Limit. Its button **Add to SideStore** links to `sidestore://source?url=https://source.cartouche.cloud`, SideStore's own link for adding a source.
- The download page has a fourth card, `download/#sidestore`, with the address, which a tap selects whole, and the same button. A link to it lights the card, as a file's does, and starts no download.
- What one needs (*Computer*: none with the player's SideStore) and the FAQ lead there. *Can I use my own certificate?* says that a copy signed by another app on the iPhone starts no game, but the one from that source, where it used to point to the roadmap for an install with no computer.

Cartouche for Mac's section says **Build for**: the paired iPhones, or a model chosen; for an iPhone 11 to 15, whose GPU reads no BC textures, it builds from **nxnative-nobc, a separate fork of nxnative by mianmuhammadse**, with a link to its repository, <https://github.com/mianmuhammadse/nxnative-nobc>, as its author asked ([decision 150](150.md)). What one needs says that an iPhone 11 to 15 plays the games Cartouche for Mac builds from it.

The site also puts forward the features it did not show yet: on a game's sheet, its description translated by the iPhone, **Edit the game's info**, a save from the console through JKSV or Checkpoint and back, Siri and the Home Screen, **Share the log**, **Import my copy** with its `romfs.img` and **Other installed apps**; behind the console, a game that turns upright with the iPhone; an install that goes on in a Live Activity; Increased Memory Limit and Game Mode, **What's new** after an update and **Report a problem**; on the Mac, its builds followed and run from the iPhone, **Build for**, and the Mac's copy of a game kept on a NAS out of Time Machine. The *On iPhone* filter counts the catalog as the app does, which `site/tests` now checks.

`site/tests` admits the source's link and nxnative-nobc's repository among the page's links, checks that the step and the card give the address and the choice to make in SideStore in the four languages, and that every link to nxnative-nobc stands beside "a separate fork of nxnative by mianmuhammadse" in each language. It amends [decision 40](../decisions.md) and [decision 155](155.md), whose page did not link to the source, and the roadmap, which kept it off the site until a trial on a real iPhone: the README waits for that trial.

**Why.** On November 25, 2026, the owner asked why the site did not offer the SideStore source, and for the site to put forward every feature of Cartouche, on the iPhone, the iPad, the Mac, Cartouche Cloud and the Installer. A player who has SideStore needs nothing else than that address, and the IPA it gives is the one copy signed elsewhere that plays games. The site says what each feature does as the app does it; the roadmap keeps what is still to try on a real device.
