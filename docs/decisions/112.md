# 112. On the Mac, Cartouche's console and the builder share one window, a switch apart

2026-11-14

Cartouche Builder's window shows Cartouche's console or the builder. **Console** and **Builder**, at the top of the window, switch between them, as ⌘1 and ⌘2 do in the View menu, and the menu bar's item opens either; the window opens on the console the first time, then on the one the player chose last ([`ConsoleWindow.swift`](../../builder/mac/Sources/CartoucheBuilder/ConsoleWindow.swift)). In the console, **Play** and **Game settings** start a game as the builder does. **Quit** asks first, as on the iPhone, then asks the game's app to quit, and stops its processes should it still run five seconds later. **Remove from this Mac** asks first, then puts the game's app in the Trash: a game built on this Mac is then built for it no longer, while a game the games folder keeps in one file (a NAS's) loses this Mac's copy alone, installed again the next time it is played. A game the games folder keeps in one file and has not installed on this Mac shows in the console as an IPA of the games folder shows in the iPhone's, with **Install from the NAS**, how far it is shown over the console. The console's Import and System lead to the builder's pages. On a game's page in the builder, what its saves did last names no device: the newest copy may come from an iPhone, an iPad ([decision 91](../decisions.md)) or another Mac. This is the fifth step of [decision 95](095.md); the app takes the name Cartouche with a release, later.

**Why.** Ad asked for the whole of Cartouche on the Mac, the console and the builder in one app, and for the player to switch from one to the other (2026-11-13). The console comes first as Cartouche's own face, the builder one switch away, and a player who works in the builder finds it again when the app opens. A game of a NAS installed on demand is to the Mac what an IPA of the games folder is to the iPhone, which the console already shows with its Install. The console's buttons are the iPhone's, and do on the Mac what the builder's own buttons do, so that a game behaves the same from either interface.
