## Discord

[Der Discord-Server von Cartouche](https://discord.gg/wG3DZjdAeF) hat Hilfe für iPhone, iPad und Mac, die Neuigkeiten jeder Version und Ecken auf Französisch, Spanisch und Deutsch.

## Gib ihnen, was sie brauchen

- **Bericht kopieren** unter jedem Fehler kopiert, was nötig ist, um ihn zu verstehen, ohne deine Passwörter oder Adressen. Füge ihn in deine Nachricht ein.
- **System › Problem melden** zeigt einen vollständigen Bericht: was du getan hast und die letzten Schritte und Fehler von Cartouche. **An Cartouche senden** sendet ihn privat an das Projekt; oder sende ihn per Nachrichten, Mail oder AirDrop an die Person, die dir hilft.
- **Protokoll teilen** auf der Infoseite eines Spiels teilt, was das Spiel während des Laufens geschrieben hat. **An Cartouche senden** entfernt vorher deine Pfade, Adressen und Namen und zeigt dir, was gesendet wird.

Auf dem Mac tun **System › Problem melden** der Konsole und **Protokoll teilen** eines Spiels dasselbe.

## Ein Fehler?

Ein Fehler kann auch auf GitHub gehen, als [Issue](https://github.com/cartouche-app/Cartouche/issues/new/choose). Issues sind öffentlich: Prüfe, was du einfügst.

:::caution
Poste nie ein Spiel, einen Schlüssel, eine Firmware oder einen Link dazu, weder auf Discord noch auf GitHub: Solche Nachrichten werden entfernt.
:::
